
FoodDonor is a Food Donation Management System developed using PHP, Laravel and MySQL. It connects food donors with NGOs to reduce food wastage and help people in need.

Project Description
FoodDonor is a web-based application that helps donors donate excess food to NGOs. Donors can submit food details, and NGOs can view, search, accept, edit, and manage donations through a dashboard. The system also tracks available, accepted, and expired food donations to reduce food wastage and support food distribution.

How to Run
Step 1: Clone the Repository
git clone https://github.com/Sakshij1904/FoodDonor.git
Step 2: Open the Project Folder
cd FoodDonor
Step 3: Install Required Packages
composer install
Step 4: Configure Database
Start XAMPP (Apache & MySQL).
Create a MySQL database.
Update the database details in the .env file.
Step 5: Generate Application Key
php artisan key:generate
Step 6: Run Database Migrations
php artisan migrate
Step 7: Start the Laravel Server
php artisan serve
Step 8: Open the Project
Open your browser and visit:
http://127.0.0.1:8000/
